# Smart Invento System

An inventory and spare parts tracking solution developed as an internship project for company use. Built with React, TypeScript, and Supabase.

## 🛠 Features
- QR-code based item scanning and verification.
- Dual-module workspace (Inventory Center & Spare Parts Hub).
- Role-based permissions and user management.
- Transaction history logs and reporting exports.

## 🔒 Confidentiality & Usage
This repository is configured for internal corporate operations. All environment variables, credentials, and configuration secrets are managed securely and must not be committed to the repository.
